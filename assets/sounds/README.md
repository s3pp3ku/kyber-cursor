# Selected third-party recordings

The owner selected these existing recordings for the public, noncommercial
Kyber project on 2026-10-17. This replaces the generated default effects and
synthetic held hum. The current Omarchy helper uses the power-up, power-down
and clash recordings. The prepared pack also contains movement and hum roles
for future runtime work.

The eleven prepared WAVs are mono PCM16 at 44.1 kHz. `manifest.json` records
source and prepared-file hashes. Preparation decodes the source MP3s and applies
a common 0.65 gain for headroom; it does not synthesize, pitch-shift or add
effects.

These are third-party recordings. Their ownership and redistribution
permissions have not been verified, and the project's MIT code license does not
cover them. Their inclusion records the owner's choice to distribute them; it
does not establish permission or suggest that short clips or noncommercial use
remove copyright. Keep this notice and the manifest with copies of the recordings.
