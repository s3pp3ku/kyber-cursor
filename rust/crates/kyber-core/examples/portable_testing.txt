KYBER CURSOR — PORTABLE VISUAL TEST

1. Copy the ZIP to your Windows PC or Mac and extract the entire folder.
2. Open portable.html in your normal web browser. No installation is needed.
3. Use Reference size and your browser's normal 100% zoom first.
4. Click Run all colors. Each color stays visible for six seconds.
5. Compare the six backgrounds. Then try each fixed glow variant on all of them.
6. Try Ignite, hold, release to check the transitions. Pause freezes a frame.
   Use 2x inspection only to examine the fade; it makes the glow look larger.

Please note any color that has a hard halo edge, looks cloudy, has weak side
blades, or loses contrast. Include the color hex value, background, glow variant,
operating system version, browser, display scaling, and whether HDR is enabled.
These details help separate rendering issues from differences between displays.
Notes in the page are not saved; copy them before closing it.

This pack uses PNG frames generated by the shared Rust renderer on Linux.
The page selects those frames; it does not redraw or recolor the glow.
It runs fully offline, sends nothing, and changes no cursor or desktop settings.
Sounds are intentionally absent.

WHAT THIS CHECKS
The appearance of the accepted compact glow, its light/dark variants, ignition,
release, and held shimmer when displayed by that machine's browser and screen.

WHAT STILL NEEDS NATIVE TESTING
Compiling and running Rust on Windows/macOS; replacing and restoring the system
cursor; global mouse-button input; pointer movement and lag; display scaling
across monitors; permissions, packaging, and recovery. The Windows/macOS cursor
backends have not been implemented. This pack is not the Windows or Mac app.

The static reference sheets are in index.html. colors.json records the palette.
